# Download the project to your Mac

## Fastest: GitHub (browser)

Click this link (raw zip):

**https://github.com/snbaskarraj/AgenticRAG-Survey/raw/main/everpuresep32026.zip**

Or open the repo and download `everpuresep32026.zip` / `everpuresep32026/DOWNLOAD_everpuresep32026.zip`.

Then on your Mac:

```bash
unzip everpuresep32026.zip
cd everpuresep32026
python3 -m pip install -r requirements.txt
./run.sh
```

Open http://localhost:8501

## Or clone the repo

```bash
git clone https://github.com/snbaskarraj/AgenticRAG-Survey.git
cd AgenticRAG-Survey/everpuresep32026
python3 -m pip install -r requirements.txt
./run.sh
```

In Cursor: **File → Open Folder → everpuresep32026**
